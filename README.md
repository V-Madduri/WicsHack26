This project was part of the WICS Hackathon at University of Texas at Austin.

One of the main constraints was to use musical elements, so we created an
app that would allow users to map music and songs they listen to certain locatins
to connect with their memories.

For example, if you associate the song "Revolving Door" with Moody Center because
that was your first concert, you can add it on as a pin on the app and the song would
show as a memory in that location.
